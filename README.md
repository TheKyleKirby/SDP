# SDP - Seagul Diesel Parts Website

## Overview

Welcome to the Seagul Diesel Parts (SDP) repository. SDP is a leading provider of high-quality diesel parts, specializing in parts and accessories for a wide range of diesel engines. The company reached out with a request to build a modern, user-friendly website to showcase their products and improve customer engagement. This repository contains the source code and resources for the development of the official SDP website.

## Project Background

Seagul Diesel Parts approached us to create a website that accurately represents their brand while offering an intuitive online shopping experience. With a goal to increase online presence and streamline the ordering process, SDP required a responsive, easy-to-navigate platform that would allow their customers to browse and purchase diesel parts efficiently. 

The website features a modern design with clear calls to action, an interactive catalog of products, and an easy-to-use interface for customers to find the parts they need.

## Technologies Used

- **HTML5**: Markup for the structure and content of the website.
- **CSS3**: Styling to create a visually appealing, modern design.
- **JavaScript**: Interactive elements and dynamic content to enhance user experience.
- **Google Fonts**: Using fonts like Yellowtail to create an attractive and legible typography style.

## Features

- Modern and editable design, making it easy for the team at SDP to update the content.
- Clear and intuitive navigation to browse product categories.
- Contact Us form for customer inquiries.
- Responsive layout optimized for both desktop and mobile devices.
- Integration of Google Fonts for unique typography.

## Installation & Usage

To get started with the project locally, clone this repository and open the `index.html` file in your browser.

```bash
git clone https://github.com/your-username/SDP.git
cd SDP
open index.html
```
